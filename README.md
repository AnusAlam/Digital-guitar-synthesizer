# Digital guitar synthesizer
This is the implementation of Karplus-Strong algorithm in Matlab. You can generate any frequency note, by giving the frequency in the code (Digital_guitar_synthesizer).

## What is MIDI_CODE_BREAK?
You can download the MIDI file of different songs from websites, it is typically include the frequency of the notes and their durations and other components. You can get the components of MIDI file by using this python program and use the components like frequency and duration in the Matlab code (Synthesized_song_1 or 2) and generate the same song from the code using only your computer.
